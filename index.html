How the three scenarios differ

  • FreshBowl: automatically approve eligible swaps; route exceptions instead of leaving every request in a manual queue.
  • CarePoint Clinics: block a swap when a required certificate has expired.
  • UrbanMart: require regional approval when a schedule takes an employee above 48 hours per week.
  • All scenarios: check training and availability before approving.

This is a front-end prototype using local sample inputs. It is not connected to Shiftwell systems, does not send approvals, and is not a production compliance tool.
