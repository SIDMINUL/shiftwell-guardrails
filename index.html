Why these checks?

  • Compliance first: required credentials must be valid for the assigned role.
  • Capability: a swap should not place an untrained employee in a role.
  • Policy-based routing: overtime or configured rules can escalate a decision to a regional approver.
  • Auditability: a production system should record the rule triggered, decision, approver, and timestamp.

This is a front-end prototype using local sample inputs. It is not connected to Shiftwell systems, does not send approvals, and is not a production compliance tool.
